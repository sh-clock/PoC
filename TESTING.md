# TESTING.md — the one-click test builds

Every release tag publishes **batteries-included** zips: the engine binary
plus its two sample scenes (the THR street and the HP0003 hospital
corridor — camdat + GLB pairs), laid out so you can unzip and immediately
run, no build, no downloads, no arguments to remember. The GLBs in the zip
are regenerated by CI from the repo's base rip files with the
`tools/ipd2gltf.py` version in the tagged commit, so every release
exercises the converter it ships.

## Zip layout

```
sh1x-poc-<tag>-linux.zip / sh1x-poc-<tag>-win.zip
├── RUN_THR.*        one-click street demo (outdoor street: fog, snow, night, flashlight)
├── RUN_HP0003.*     one-click hospital corridor demo (interior env)
├── fog_poc | fog_poc.exe
├── input/
│   ├── THRF9FD.glb, camdat.json
│   └── HP0003.glb, hp_camdat.json
├── README.txt       quick instructions + the license disclaimers
├── TESTING.md, ACKNOWLEDGEMENTS.md, TOOLS.md
```

`.sh` runners on Linux/macOS; `.bat` on Windows (the Windows zip also
keeps `.sh` for Git-Bash/WSL users — they invoke `fog_poc.exe`).

## One-click run

* **Linux / macOS** — unzip, then:
  * `./RUN_THR.sh` — the street demo (realtime window, native 320×224,
    engine-exact fog + snow + night + flashlight; keys `N` night,
    `F` flashlight, `W` weather, `P` wobble, `H` HUD — see the repo README).
  * `./RUN_HP0003.sh` — the hospital corridor.
* **Windows** — unzip, then double-click or run:
  * `RUN_THR.bat`, `RUN_HP0003.bat`.

## Deterministic self-test (no window, CI-style)

Each runner also has a `--test` mode that renders a deterministic PNG via
`--shot` — this is exactly what CI asserts on every push, and it needs no
display (works over SSH/in containers):

```
./RUN_THR.sh --test          # renders shots/SELFTEST_THR.png
./RUN_HP0003.sh --test       # renders shots/SELFTEST_HP0003.png
RUN_THR.bat --test           # Windows (shots\SELFTEST_THR.png)
```

Pass = the PNG is produced under `shots/`, and it is byte-identical
across runs — the determinism proof is to run twice and `cmp` the files. For a visual check,
open the PNG: the THR shot shows the fogged night street
with snow at 10.5 s into the track; the HP0003 shot shows the day-lit
hospital corridor at 6 s

## What the two scenes demonstrate

| Scene | Engine features exercised |
|---|---|
| THR street (`THRF9FD.glb` + `camdat.json`) | outdoor fog preset 1, snow system (300 flakes, BG_ETC sprites), night pair {6,3} + per-vertex flashlight (camdat `env`), turn filter, PSX wobble, 30 fps lockstep |
| HP0003 hospital (`HP0003.glb` + `hp_camdat.json`) | interior preset pair, no-particles rule (engine: interiors have no weather), OT layering + billboard billboards, the same renderer with a second room |

Both scenes use the same binary — swap the GLB/camdat pair to test any
other room you convert yourself (see [TOOLS.md](TOOLS.md)).
